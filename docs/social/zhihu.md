# 我做了一个跨平台的笔记本电源管理小工具：ClearPower

一直想要一个这样的电源管理软件：轻量，可视化做得好，最好 Linux、macOS、Windows 都能用。插着电的时候能设充电上限，让电池别总停在 100%，多用几年；用电池的时候能看到电到底耗在哪、还能用多久。能找到的要么只管一个平台，要么数字是估出来的，要么后台本身就不轻。于是自己写了一个，叫 ClearPower，现在是 0.5.1，三个平台的安装包都有，开源。

![ClearPower](./1-cover.png)

## 插着电：充电上限

托盘或菜单栏点一下，上限在 80、90、100 之间切换，设置里 50 到 100 都可以选。另外两个按钮是我自己用下来觉得必须有的：**补满**，出门前点一下充到 100%，回来自动恢复上限；**放电**，电池已经充到 95% 的话直接放回上限，不用等它自己慢慢掉。放电需要固件配合，目前 ThinkPad 和 Apple Silicon 的 Mac 可以。

![设好上限，电池的事就不用再管了](./2-charge.png)

写阈值这件事三个平台各走各的路：Linux 写 sysfs，macOS 由一个小的特权助手写 SMC（安装时输一次管理员密码），Windows 走联想 Power Manager 的接口写 EC，不装驱动，也不要管理员权限。

## 用电池：看清功耗和剩余时间

可视化我有一个要求：图里的数字得是真的。所以 ClearPower 里的每个数都是传感器测出来的，分项加起来正好等于整机，不是模型估的。

![每一瓦去了哪，一张图就看清了](./4-flow.png)

弹窗里是一条流：适配器/电池 → 整机 → CPU、GPU、SoC、内存、屏幕、其他。CPU、显卡、内存读芯片自己的能量计数器，整机在用电池时读电池的电量计，没有传感器的 SSD、Wi-Fi、USB 这些用整机减掉已知的部分，归到"其他"。

屏幕是单独做的。面板没有功耗传感器，厂商也不给数据，所以我做了一个校准：显示全白屏、扫一遍亮度，从整机功耗的变化反推出这块面板的曲线，之后按画面内容缩放。结果差距很大：同一块 OLED、同样的亮度，白底网页 7 W，深色桌面 0.4 W。

![换个深色主题，屏幕功耗从 7 W 降到 0.4 W](./3-screen.png)

剩余时间按电池最近 10 分钟、30 分钟、1 小时的实际耗电算，比系统那个瞬时估计稳。温度、风扇、电源模式、哪个应用在耗电，也都在同一个弹窗里。

## 轻量

一个小进程。弹窗关着的时候降低采样频率，不画图，温度和进程列表要看了才查。一个看功耗的工具，自己不能是耗电大户。

![还能用多久算得稳，平时也不碍事](./5-runtime.png)

## 目前的限制

- 完整功耗分解需要 Intel（RAPL）或 Apple Silicon，AMD 还没做
- 充电上限目前支持 ThinkPad（以及有内核阈值接口的品牌）和全部 Apple Silicon Mac
- Windows 插着电时整机功耗只能估算，会标 ≈，因为 Windows 不提供整机功耗传感器
